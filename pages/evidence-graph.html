Evidence Graph
Framework

Every claim is a liability without proof. Every structured proof object is a citation asset. The CHAOS RANK evidence graph is the machine-readable foundation of AI-search authority.

What Is an Evidence Graph?

An evidence graph is a structured collection of machine-readable proof objects. Each object represents a claim — an assertion that an entity, fact, or principle is true — along with its source, evidence strength, and a canonical URL pointing to supporting content.

In the CHAOS RANK system, the evidence graph is stored in /data/claims.json — a public, machine-readable JSON file that AI crawlers can index and parse directly.

Anatomy of a Proof Object

// Proof Object Schema

{
  "id":                "string — unique identifier",
  "claim":             "string — the declarative assertion",
  "topic":             "string — category classification",
  "evidence_strength": "low | medium | high | strong",
  "source_type":       "UGC | Research | Internal | Doctrine",
  "canonical_url":     "string — page supporting this claim",
  "schema_type":       "Claim | Article | FAQPage",
  "verified":          "boolean — human-verified flag"
}

Evidence Strength Scale

  • Low — Single source, unverified, speculative
  • Medium — Multiple sources, partially verified, plausible
  • High — Multiple corroborating sources, human verified
  • Strong — Extensive evidence, universally accepted in domain

How Claims Enter the Graph

Path 1: UGC Signal

The UGC HARVESTER collects organic discourse, scores claim candidates by quality, and passes high-scoring claims to the EVIDENCE GRAPH skill for structuring.

Path 2: Research Input

Published research, data analyses, and documented observations enter the graph with source attribution and evidence strength scoring based on the research methodology.

Path 3: Doctrine

Core AGENTOPOLIS operational principles enter the graph as Doctrine-type claims with Strong evidence strength — these are the axioms the entire district operates on.

Path 4: Internal Validation

Internal tests, GEO audit results, and prompt tracking data generate Internal-type claims that update the corpus with empirical evidence.

The Graph as Infrastructure

The evidence graph is not documentation. It is infrastructure. When an LLM indexes /data/claims.json, it receives a machine-parseable corpus of structured assertions with sources and canonical URLs. The LLM can follow canonical URLs to verify claims. The LLM can use evidence strength scores to weight its confidence.

This is what makes the evidence graph an LLM backlink — not a hyperlink, but a structured pathway to verified information that AI systems can trust and cite.

Adding Claims to the Graph

To add a new claim to the CHAOS RANK evidence graph:

  • Fork the repository at GitHub
  • Edit /data/claims.json following the proof object schema
  • Ensure the canonical_url points to an existing published page
  • Set "verified": false until the claim is independently validated
  • Submit a pull request with the claim source documented
